Privacy Policy

Last updated: November 19, 2026

GChat Auto Translator ("the Extension") is a Chrome browser extension that automatically translates messages in Google Chat. This Privacy Policy explains what data the Extension collects, how it is used, and how it is protected.

1. Data We Collect

The Extension collects and processes the following data solely for the purpose of translation:

  • Message text – The text of Google Chat messages you receive (and the messages you type, when outgoing translation is on) is sent to the translation service you select in the settings (see Section 3). When you select an AI engine (Gemini, Claude or ChatGPT), up to three earlier messages in the same conversation are also sent as context to improve translation quality.
  • User preferences – Language settings, toggle preferences, translation engine and tone, your glossary, and any API keys you enter are stored locally in your browser using chrome.storage.local. An API key is sent only to the service it belongs to, as required to authenticate translation requests.
  • Per-chat settings – For each chat room, the Extension may store the room identifier (taken from the page address) together with a language code or an on/off flag in chrome.storage.local, so that it can remember which language to use for that room and whether translation is turned off there. No message text is stored for this purpose.
  • Translation cache – To avoid translating the same text repeatedly, recent message texts and their translations (up to 500 entries) are kept in chrome.storage.session, an in-memory browser storage area that is cleared when the browser is closed.

2. Data We Do NOT Collect

  • We do not collect, store, or transmit any personal information to our own servers. The Extension has no server of its own.
  • We do not track browsing history or activity beyond what is necessary to translate visible Google Chat messages.
  • We do not share any data with third parties other than the translation services described in Section 3.

3. Third-Party Services

Message text is sent only to the translation service you select in the Extension settings. By default this is Google Translate (free endpoint).

  • Google Translate (free endpoint) – The default engine, used when no API key is required or provided. This is an unofficial endpoint; usage is subject to Google's general Privacy Policy.
  • Google Cloud Translation API (optional, requires your own API key) – Subject to the Google Cloud Privacy Notice.
  • Google Gemini API (optional, requires your own API key) – Subject to the Gemini API Additional Terms and Google's Privacy Policy.
  • Anthropic Claude API (optional, requires your own API key) – Subject to Anthropic's Privacy Policy.
  • OpenAI API (optional, requires your own API key) – Subject to OpenAI's Privacy Policy.

Fallback option – If you turn on "fall back to Google free translation on failure" (off by default), text that your selected engine fails to translate is also sent to Google Translate (free endpoint).

Text sent to these services is governed by each provider's privacy policy and terms of service. We encourage you to review those policies.

4. Permissions Explained

  • storage – Saves your preferences, per-chat settings and the translation cache in the browser.
  • host_permissions (chat.google.com, mail.google.com) – Required to read and modify Google Chat message content for translation.
  • host_permissions (translate.googleapis.com, translation.googleapis.com, generativelanguage.googleapis.com, api.anthropic.com, api.openai.com) – Required to send text to the translation service you select and receive translated results.

5. Data Retention

The Extension does not keep message text beyond the translation cache described in Section 1, which is cleared when the browser is closed. Preferences and per-chat settings are stored locally in your browser and can be cleared at any time by removing the Extension or clearing browser storage. Data sent to a translation service is retained according to that provider's policy.

6. Children's Privacy

The Extension is not directed at children under the age of 13. We do not knowingly collect personal information from children.

7. Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be reflected on this page with an updated "Last updated" date.
